# Preview data

The nine OSM map tiles are a small cached fixture around the sample position
31.2304, 121.4737 at zoom 12. Map data © OpenStreetMap contributors:
https://www.openstreetmap.org/copyright . They are map data, not device screenshots.

The KML route is synthetic and is provided only to exercise the firmware route
and elevation interface. It is not an itinerary or a recommended walking route.
