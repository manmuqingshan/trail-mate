P1 · [Design not formed] Configuration lacks version, verification and atomic commit owner

Design defect · Acknowledged

Current issues

MeshConfig、AppConfig, default values, compatible conversions and platform store share configuration responsibilities, there is no schema version, unified validation and atomic commit owner.

Target language

ConfigurationSnapshot, typed settings, ConfigurationPolicy, ConfigurationService and IConfigurationStore.

Target rules include: invalid configuration is not partially written; migration is repeatable; platform store does not define business default values; unsupported capabilities cannot be forced to be enabled by configuration.
