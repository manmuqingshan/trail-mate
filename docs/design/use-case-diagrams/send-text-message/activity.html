消息提交与发送

flowchart TD
Compose["提交文本"] --> Validate{"目标与密钥有效?"}
Validate -- 否 --> Reject["拒绝"]
Validate -- 是 --> Queue["消息身份 + Queued"]
Queue --> Encode["协议编码"]
Encode --> Radio["radio queue"]
Radio --> Sent["Sent"]
Sent --> Ack{"ACK?"}
Ack -- 是 --> Delivered["Delivered"]
Ack -- 超时 --> Failed["Failed"]
