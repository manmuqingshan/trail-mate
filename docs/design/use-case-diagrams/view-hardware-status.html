场景路径

主成功路径

  1. 用户选择查看硬件状态
  2. 系统依次检查 GPS、无线电、传感器、SD 卡、电池等
  3. 系统显示每个硬件的状态（就绪/未就绪/错误）及电池电量、温度、充电状态
  4. 用户选择硬件状态页面
  5. 系统逐一查询各个硬件模块的状态并显示

备选路径

  1. 无

失败路径

  1. 某硬件不可用时显示为未就绪，不影响其他硬件检查
  2. 某个硬件模块无响应，显示未就绪
