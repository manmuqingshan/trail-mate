场景路径

主成功路径

  1. 1. 用户输入文本并触发发送
  2. 2. 系统通过 ChatService 将消息打包
  3. 3. 通过 MeshAdapter 发送到网络
  4. 4. 显示发送成功反馈
  5. 用户在聊天页面输入消息并触发发送命令
  6. 系统将消息打包并通过无线电发送
  7. 系统将发出的消息添加到本地历史记录
  8. 用户编写文本消息
  9. 用户触发发送
  10. 系统将消息封装并通过无线电发射

备选路径

  1. 无

失败路径

  1. 无线电通道忙碌或超时，向用户显示发送失败提示
  2. 无线电发送失败，系统显示错误提示
