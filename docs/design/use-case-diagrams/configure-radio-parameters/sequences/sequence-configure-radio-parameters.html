Settings 到活动 backend

sequenceDiagram
actor U as 用户
participant S as Settings
participant C as AppConfig
participant R as MeshAdapterRouter
participant P as 协议分区存储
participant Radio as Radio owner
U->>S: 保存配置
S->>C: validate
S->>R: installBackend
R->>Radio: stop old
R->>P: load partition
R->>Radio: start new
Radio-->>R: result
R-->>S: committed or error
