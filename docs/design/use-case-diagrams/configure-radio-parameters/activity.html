协议切换与提交

flowchart TD
Edit["编辑协议配置"] --> Validate{"能力和参数有效?"}
Validate -- 否 --> Reject["保留旧协议"]
Validate -- 是 --> Stop["停止旧 backend"]
Stop --> Load["加载新协议分区"]
Load --> Start{"启动成功?"}
Start -- 否 --> Safe["保持 stopped/error"]
Start -- 是 --> Persist{"保存成功?"}
Persist -- 否 --> Unsaved["运行但未保存"]
Persist -- 是 --> Commit["提交并刷新"]
