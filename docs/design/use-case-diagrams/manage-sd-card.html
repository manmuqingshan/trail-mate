场景路径

主成功路径

  1. 用户插入 SD 卡或选择安装/检查
  2. 系统尝试初始化 SD 卡，进行就绪检查
  3. 系统更新 SD 卡状态，如果就绪则允许日志、数据等存入 SD 卡
  4. 用户进入 SD 卡管理
  5. 系统检测 SD 卡状态
  6. 用户选择挂载或卸载，系统执行操作

备选路径

  1. 无

失败路径

  1. SD 卡未插入或损坏，提示错误并显示未就绪
  2. SD 卡未插入，操作失败
