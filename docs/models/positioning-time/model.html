GNSS 定位、跳变过滤与时间更新

真实状态

服务保存 latest_fix_、last_fix_revision_ 和 last_time_revision_。ITimeAuthorityUpdater 是输出端口，不是名为 GNSS Time Authority 的领域实体。

边界

路线进度和偏航策略不属于 LocationFix；它们作为 Navigation 模型缺口留在 Review Queue。
