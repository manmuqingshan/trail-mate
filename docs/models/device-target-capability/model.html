设备目标、能力与权威模型

目标具有什么能力、当前是否可用、资源由谁控制。

confirmed4 elements

模型判断

代码被编译进目标不等于功能可用。manifest、runtime status 和 authority binding 共同形成产品能力事实。

不变量

  1. 未声明能力默认为不可用。
  2. 同一受控资源只有一个 authority owner。
  3. 不可用和降级携带可诊断原因。
  4. UI 不用平台宏猜测能力。

领域元素

TargetManifestView — 静态目标契约。

CapabilityKind / CapabilityStatus — 能力语言与运行状态。

AuthorityBinding — 资源到 owner 的绑定。
