Peer observation, contact promotion and local trust

After protocol observation enters the directory, it forms protocol facts, observation facts and local user facts respectively; contact deletion and node deletion have different semantics.

flowchart LR

Directory --> Ignore[ignored]
Directory --> Trust[trusted / verified projection]
Contact --> RemoveContact[Delete only nickname]
Directory --> RemoveNode[Delete node and nickname]
