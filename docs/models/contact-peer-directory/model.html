联系人、对端目录与本地信任模型

该模型拥有本地对端目录、联系人 nickname、协议分区、ignored 与 trust 投影。消息模型使用它，但不拥有它。

实际边界

  • MeshPeerIdentity / MeshPeerRecord：跨协议目录记录。
  • IMeshPeerDirectory：目录写入、查询、flags、删除与 flush。
  • ContactService：旧节点/联系人投影及用户动作。
  • INodeStore / IContactStore：节点观察和 nickname 的独立持久化。

尚未闭合

新旧两套目录表达并存；isNodeVisible() 当前无条件返回 true；trusted、manually verified 与 Mesh verified key 没有统一证明语义；协议身份到业务联系人的 IdentityLink 尚未形成。
