# 完整页面状态与输入契约

状态：待评审设计，未开发页面。适用480×222和320×240；本文件补齐07四种静态稿未展开的状态，不新增网络操作。

## 1. 统一导航与焦点

页面栈保存route、分区、选中完整cache_id/hash、滚动位置、筛选草稿和返回地图视口。用完整对象身份恢复，不保存临时地图slot。返回键只关闭最上层；不得同时取消网络任务和退出两层页面。

列表上下选项、左右换分区；进入弹层后方向键只操作弹层，不穿透地图。触控和键盘触发同一动作sink。按钮强调色与键盘焦点分别呈现，不能以颜色猜当前会执行哪个动作。

超长名称单行省略，详情可阅读完整文字；UTF-8按字符边界截取显示，不修改协议原文。正文使用可滚动阅读区，提供明确返回操作区入口。无触屏设备所有操作必须从焦点序列可达；触屏目标不能照搬28px小按钮，采用07规定的较大点击区或主按钮加更多页。

## 3. 发现列表的完整状态

| 数据/网络状态 | 显示 | 可操作 | 不允许 |
| --- | --- | --- | --- |
| 首次未启用 | 公共查询会把所选区域发给目录的说明 | 启用、返回 | 自动上传当前位置或轨迹 |
| 存储恢复中 | 正在恢复本地数据 | 返回 | 显示“没有下载”并允许覆盖 |
| 无目录候选 | 正在发现公共目录；本地内容入口 | 返回、看已下载 | 假造全网空结果 |
| 有候选，能力未确认 | 正在检查公共目录 | 返回 | 把普通LXMF节点当目录 |
| 查询中，有旧结果 | 保留旧列表并标记更新中 | 浏览旧结果、停止后续分页 | 清空屏幕或把旧结果当新查询 |
| 完成且无结果 | 当前已发现目录无匹配结果 | 调区域/筛选、刷新 | “全网没有宝藏” |
| 部分目录成功 | 合并结果，标记部分目录未完成 | 浏览、查看活动 | 整页报失败抹掉成功项 |
| 全部暂不可达 | 查询未完成，可查看已有缓存 | 稍后刷新、已下载 | 将缓存时间改成现在 |
| 更多页 | 有更多结果入口 | 加载更多 | 无限滚动触发无界请求 |
| 候选/结果截断 | 当前显示范围有限 | 缩小区域、翻页 | 显示已包含全网 |

停止查询只停止后续自动页，当前响应可以进入有界缓存但不跳回页面。新区域查询使用新的view_generation；旧结果回到旧会话，不污染当前筛选列表。

## 4. 筛选契约

第一版网络筛选：地图bbox、active/disabled/archived三态多选、可选作者公钥hash。普通入口默认active+disabled；高级作者筛选输入必须是完整32字节hash的64位hex，不接受昵称模糊匹配。

难度、距离、已下载、已找到过滤仅对已收到/本地内容生效，界面标记“在已加载结果中筛选”；不能向用户暗示服务端全库筛选。v1没有全文搜索和服务端距离排序。

筛选页修改先保存在局部草稿；返回丢弃未应用修改，不发送请求；“重置”只重置草稿；“应用并查询”验证至少一种状态后创建新query会话。无定位仍可用地图区域，不自动把bbox设成(0,0)。跨日期变更线由业务拆成两个合法请求，界面仍显示一个选择区域。

## 5. 详情状态与动作

| 状态 | 主动作 | 其他动作 | 状态说明 |
| --- | --- | --- | --- |
| 仅摘要 | 下载详情 | 地图查看、返回 | 尚未完成作者验证 |
| 下载中 | 查看进度 | 停止后续尝试、返回 | 关闭页不自动取消任务 |
| 已验证可寻找 | 前往 | 提示、个人记录、检查更新、更多 | 展示最后检查时间 |
| 已暂停 | 查看说明 | 检查更新、个人记录、地图查看 | 不作为正常寻宝出发推荐 |
| 作者已撤下 | 查看历史 | 个人记录、更多 | 不显示“前往寻宝”主按钮 |
| 历史待核实 | 查看核实情况 | 查看已有内容、明确取证 | 不把疑点写成作者分叉 |
| 已证实冲突 | 查看冲突证据 | 个人记录、已有版本阅读 | 停止自动选择当前版本 |
| 本地原文不可读 | 重试读取 | 查看摘要、存储诊断 | 不显示已可离线使用 |
| 来源不提供该版本 | 刷新公开发现 | 其他提供者精确下载 | 不暗换版本 |

地图查看只把位置居中，与设为导航目标不同。摘要中的坐标可以查看，但未验签详情不自动成为可信导航目标。个人记录可保留，即使作者撤下。

## 6. 编辑器与坐标输入

编辑器字段顺序：名称 → 位置 → 介绍 → 提示 → 难度 → 地形 → 容器大小 → 初始/新维护状态。320×240每页显示有限字段并滚动；480×222可左右布局标签和输入，但不复制业务状态。

名称必填且不能全空白；正文和提示允许空；难度/地形以0.5步进，默认1.0；容器默认未说明；首次默认active。长度计数是UTF-8字节，不是字数，达到上限拒绝进一步输入并保留已有文本。

坐标提供地图选点、使用当前位置和手工输入三种入口。使用当前位置必须有有效定位并显示精度/时间供用户确认；无fix不填假坐标。手工输入为带正负号的十进制度，经纬分别输入；拒绝NaN、无穷、空字段、越界与非数字。可接受超过7位小数，预览显示规范量化后的7位结果；发布以预览结果编码。

地图选位置是独立选择模式，确认只写回草稿，不发布、不设置导航目标；返回保持原草稿坐标。作者身份在编辑会话中可看见；身份不可用保留草稿，但禁用签发。

离开有未保存编辑的页面，提供“保存草稿/放弃修改/继续编辑”。保存草稿是本地事务，成功后才退出；存储错误保留编辑缓冲并提示，不悄悄退出丢字。

## 7. 签发、发布和未确认版本

“预览”不签名；进入发布确认先验证所有字段并显示规范坐标、作者、状态和公开说明。“公开发布”动作在业务层串行锁定作者版本、签名并持久保存签发事实，再生成请求。

已存在未确认的同ID发布时，默认提供“查看前次进度/保存新草稿/返回”，不自动并发签发覆盖。用户可以明确选择“仍生成后继版本”，说明前次可能已经公开；后一版本递增并引用已签发前驱。

签名生成后即使不再发送也不重用revision。再编辑产生后继，确认页显示跳号/未公开前驱提示。删除草稿不会删除签发账本。发布结果只统计本版本入口确认，不把v1成功计作v2成功。

公开确认默认焦点停在“返回编辑”，主按钮样式可以强调公开发布，但不得让快速连按意外发布。没有终端支持情况或网络可见性的虚假百分比。

## 8. 个人记录与删除

记录结果选项为未记录、找到、未找到，另有≤2048字节本地笔记；保存后返回原详情焦点。保存失败保留输入，不能用关闭弹层暗示成功。结果不是作者维护状态，不发网络消息。

删除分两种明确动作：删除已下载副本；删除个人记录。默认只删副本并保留记录/作者签发/防回退记忆。全部清除属于设置中的高级动作，说明丢失本地记忆但不撤下网络内容，不能混在列表一键删除中。

删除副本先提升安装generation再执行，迟到下载不能恢复它。已经删除的详情返回列表，不继续显示可导航的已下载标记。

## 9. 活动与错误反馈

活动页按用户任务聚合；展开可看入口子请求、结果码和时间。日常文案不要求用户理解cursor/epoch；这些放诊断。

| 事件 | 提示级别 | 用户后续动作 |
| --- | --- | --- |
| 单个目录暂时超时 | 活动行状态 | 等待/原请求重试 |
| 至少一个入口公开接纳 | 一次成功反馈 | 查看发布，继续传播 |
| 重复200/传播重复投递 | 不重复弹出 | 无 |
| 身份密钥缺失 | 阻止发布的明确错误 | 恢复身份或保留草稿 |
| SD不可用/只读 | 页面状态条和操作失败 | 恢复介质，不改用未知Flash区 |
| 签名错误/来源违规 | 下载错误及诊断 | 换已知提供者或稍后刷新 |
| 迟到成功且任务已停止 | 活动页“迟到确认” | 不抢焦点，不重开页面 |
| 新有效版本 | 当前详情更新说明 | 坐标改变时明确显示更新，不静默移动正在使用的导航目标 |

正在导航时收到新坐标：下载对象可以更新，但导航目标作为独立会话保留原目标，提示“藏宝点位置已更新，是否切换目标”；只有明确动作才改变目标。若新状态archived/disabled，显示警示并提供停止导航，不能悄悄清掉用户当前地图任务。真实导航owner接入仍按08/11后续核查。
