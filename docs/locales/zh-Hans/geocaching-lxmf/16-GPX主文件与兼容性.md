# SD卡上的GPX主文件与广泛兼容性

状态：按用户明确要求重设计，尚待完善评审。用户可见存储必须采用GPX主文件，不再采用14中的.gco私有主格式。

## 1. 已确认需求及变更

用户需要SD卡上的实际文件可以广泛用于地图、GPS与寻宝软件；不是保存私有数据后再提供一个将来的导出按钮。下载保存成功后，SD卡上就应有可直接复制、导入的GPX。

GPX本身提供waypoint等交换结构；geocaching软件也使用包含寻宝专用信息的GPX。使用这一格式不意味着依赖geocaching.com服务或从其网站下载数据。[GPX 1.1规范](https://www.topografix.com/GPX/1/1/)、[Geocaching软件说明](https://www.geocaching.com/software/)。

## 2. 主文件候选

采用GPX 1.1，每个点一个.gpx，使用wpt。标准字段包含坐标、名称和纯文本说明，寻宝属性与原作者签名信息使用扩展。普通软件忽略扩展后仍可读取基础标点。

```text
SD:/trailmate/geocaching/
  caches/<完整cache_id小写hex>.gpx
  imports/                    # 用户放入外部GPX，原文件保留
  .state/                     # 索引、请求与恢复辅助数据
```

上述路径是候选，不声称其他硬件会自动扫描该目录。文件格式兼容与厂商扫描目录约定分开；复制或导入GPX是最低兼容路径。批量多wpt文件的输入输出也纳入设计。

## 3. 信息映射与兼容层次

| 信息 | GPX候选表达 | 忽略扩展后 |
| --- | --- | --- |
| 坐标 | wpt的lat/lon十进制度 | 仍可定位 |
| 名称 | wpt/name | 仍可识别 |
| 描述 | wpt/desc纯文本 | 仍可阅读 |
| 时间 | 有有效时间时wpt/time | 不生成假1970时间 |
| 提示、难度、地形、容器和状态 | 寻宝扩展，并在标准描述中保留可读说明 | 普通地图软件也能读关键说明 |
| 稳定ID、版本与作者公钥 | 应用扩展 | 无扩展时不保证保留协议身份 |
| 精确record_bytes及签名 | 应用扩展保存原字节 | 丢失后不能继续标为作者已验证 |

寻宝扩展现按21提出Groundspeak1.0.1配置，已通过HTTPS取得并解析官方schema；此前网页工具失败已经解决。仍不得伪造GC编号、平台账号或网址来换取识别。基础GPX、寻宝语义和作者签名是三个分别验证的兼容层次，真实软件识别尚未实测。

## 4. 外部软件改写与作者验证

签名针对作者发布的精确记录字节，不对随软件重排的XML全文做不稳定的字节签名。读取保留扩展的GPX时，先验证原文签名，再核对GPX可见字段与原文映射是否一致。

| 情况 | 处理 |
| --- | --- |
| XML排版/属性顺序变化但语义一致 | 可以恢复已验证对象，不因空白变化失效 |
| 坐标/描述被修改，但仍附旧签名 | 标记外部内容与签名不一致，保留用户文件，不冒充作者更新 |
| 自定义扩展丢失 | 作为普通GPX导入点使用，来源未验证 |
| 签名/原文损坏 | 不进入已验证公共对象，可查看错误或按普通导入处理 |

普通GPX导入不自动公开。用户明确“作为我的新藏宝点发布”时使用自己的身份生成新ID，不能凭外部ID取得原作者修改权。未知扩展不能阻止读取合法基础坐标；具体保留和限额规则仍须补齐。

## 5. 网络与落盘分开

用户本次明确的是文件兼容性，不自动等于LXMF必须发送XML。当前候选仍以紧凑签名记录通过LXMF传输，接收后生成GPX主文件；其扩展可保存原签名对象以供验证和再次传播。

内部日志只负责恢复和请求状态，不能成为普通软件读取GPX的必要条件。存储port只有在GPX已完成校验和持久安装后才报告下载保存成功，不能只写完私有账本就显示完成。

## 6. 必须完成的后续设计

标准字段、签名扩展候选、导入分类和安装恢复已具体化为[GPX字段与外部编辑契约](./17-GPX字段与外部编辑契约.md)。寻宝专用第三方扩展与真实软件验证仍未完成，不将基础GPX合法性等同完整寻宝兼容。

1. GPX根namespace、元素顺序、字段映射、UTF-8/XML转义和时间格式。
2. 具体寻宝扩展及其软件支持，避免假冒其他平台标识。
3. 作者原字节/签名扩展的确切字段、编码和上限。
4. 外部改写、无扩展、重复ID、多wpt、未知扩展的导入行为。
5. GPX临时写入、校验、替换和辅助事务的掉电恢复。
6. 单点/批量静态GPX样例、schema校验和真实软件兼容矩阵。

14已改成GPX主文件与Prepared/Installed恢复协议，不再生成私有.gco主内容。寻宝软件专用扩展和实际兼容验证仍需继续，不能因物理格式改完就称广泛兼容已验证。
