# 五种操作的完整静态请求/响应

[five-operation-pairs.json](./five-operation-pairs.json)包含capabilities/publish/query/get/sync全部五对有效示例，使用SIGNED-VECTOR中的公开测试对象。JSON中的bin_hex是文档显示约定；在线数据是对应二进制，不是这个JSON。

| 操作 | 请求字节 | 响应字节 | 场景 |
| --- | --- | --- | --- |
| capabilities | 26 | 81 | 公共目录完整五操作能力 |
| publish | 216 | 131 | 首次接纳测试对象v1 |
| query | 51 | 141 | 区域内一个结果，末页游标nil |
| get | 95 | 217 | 精确下载测试对象hash |
| sync | 28 | 140 | 单对象基线末页，转增量检查点 |

每对请求ID不同，分别为01、02、03、04、05重复16次，避免同一来源复用请求ID的歧义。snapshot/epoch/cursor为静态占位字节，仅用于校验形状，不是真实服务颁发的可用游标。

由离线文档脚本序列化，另用独立的样例标签读取逻辑核对全部10份字节还原到记录的逻辑值，检查无尾随字节、请求/响应operation与ID相同、响应不超过请求预算。实际结果全部通过。

没有发送LXMF、运行协议服务或替产品编写解析器；没有完整外层身份/时间戳/stamp。标准LXMF外层由所选实现负责，字段和签名依据见13。此文档附件提供可复算的应用层合同，不声称所有边界测试已通过。
