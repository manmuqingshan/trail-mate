# Local Chinese-source archive

This directory is reserved for a locally retained copy of the former Chinese
documentation. During the migration of an existing checkout, those source
documents are placed under `source/` with their prior repository-relative
paths preserved.

`source/` is intentionally ignored. It is a local preservation archive, not a
second documentation tree to be reviewed, linked, or shipped by Git. The
tracked documentation in this repository is the complete English canonical
version.

Normal development and builds do not need anything in `source/`. Do not add
files from that directory to commits.
